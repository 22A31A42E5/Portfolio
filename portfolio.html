    SHL Assessment Recommendation Engine

    PROBLEM

    Matching a job description to the right assessments by keyword is unreliable. The goal was to recommend relevant SHL assessments from free-text job descriptions or queries.

    APPROACH

    An embedding-based semantic recommendation and retrieval system: assessments and queries are turned into vectors, and the closest assessments are returned by similarity.

    HOW IT WORKS

    1. Load assessment data with Pandas (including final_tests.csv).
    2. Create text embeddings with sentence-transformers (all-MiniLM-L6-v2).
    3. Index them with FAISS for similarity-based retrieval.
    4. Embed the user's query and retrieve the most similar assessments.
    5. Serve results through FastAPI, with a Streamlit interface.

    EVALUATION

    Evaluated with MAP@3 and Recall@3.

    RESULTS

    MAP@3: 0.56 and Recall@3: 0.50.

    GITHUB AND DEPLOYMENT

    Code is in a public GitHub repository (shl_recommendation_engine). I worked with deployment using Streamlit, Render and Hugging Face Spaces. A public demo link is not listed here.
